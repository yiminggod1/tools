这份分数代表什么？

RIG 是本应用内的 0–100 性能画像，不是行业标准，也不冒充硬件认证。完整跑完三项后，按以下权重加权；未测项目不计入，并标出完成率。

CPU · 80,000,000 次基准运算 / 秒 = 100 分40%
GPU · 1280×720、12 次迭代、GPU 执行 16.67 ms = 100 分40%
内存 · 25,000 MB/s 实际读写 = 100 分20%
  • 单项分数到 100 封顶，低于基准按比例显示。
  • GPU timer query 不可用时保留呈现 FPS，但不把显示器刷新率冒充 GPU 速度，也不计 GPU 子分。
  • 5K 测试会渲染 14,745,600 像素，单帧缓冲约 56 MiB；必须受设备尺寸上限约束。
  • 不同系统、应用版本和散热环境会影响结果；适合用同一档位对比同一台设备。
